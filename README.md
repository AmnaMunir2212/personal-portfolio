# Amna Munir — Personal Portfolio

A clean, responsive personal portfolio website built with vanilla HTML, CSS, and JavaScript. Showcases my background as a Software Engineering student, frontend developer, and UI/UX designer.

🔗 **Live Site:** https://amna-munir-portfolio11.netlify.app/

---

## ✨ Features

- Fully responsive, mobile-first layout
- Dark / light theme toggle
- Smooth animations and hover interactions
- Clean, modern design system built entirely with CSS custom properties (no frameworks)
- Fast-loading, single-page structure — no build tools required

---

## 🛠️ Built With

- **HTML5** : semantic structure
- **CSS3** : custom properties, responsive grid/flexbox layouts, gradients
- **JavaScript** : theme toggling, interactivity
- **Google Fonts** : Fraunces (serif headings) + Inter (body) + JetBrains Mono (accents)
